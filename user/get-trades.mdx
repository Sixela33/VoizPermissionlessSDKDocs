---
title: "Get trades"
description: "Indexed Buy / Sell fills for a wallet."
---

You want the fill tape for a wallet that bought Yes on the ETH market. These are buy and sell events. They are not remaining shares and not liquidity lots.

You get a user from `client.user(address)`, not from the package root. If the indexer is down, you get an empty list. Trading still works off the chain.

Do not mix the three lists. Remaining Yes and No: [share positions](/user/get-share-positions). Pool shares: [LP positions](/user/get-lp-positions).

| Method | Book |
| ------ | ---- |
| `trades()` | OutcomeAmm `Buy` / `Sell` fills |
| `sharePositions()` | Indexer `sharePosition` only (no live ERC-20 overlay) |
| `lpPositions()` | OutcomeAmm ERC-20 pool shares (one lot per market) |

```ts
const user = client.user(address)
const fills = await user.trades({ market, limit: 50 })
```

```ts
Promise<Array<{
  id: string
  marketId: Address
  marketName: string
  outcomeIndex: number
  outcomeLabel: string
  side: "buy" | "sell"
  outcomeAmount: bigint
  collateralAmount: bigint
  priceCt: number
  timestamp: string
  transactionHash: Hex
}>>
```

`UserTradesParams`: `market?: Address`, `limit?: number`. Swap fees live in the indexer `hook_fee` table, not on the trade row.
