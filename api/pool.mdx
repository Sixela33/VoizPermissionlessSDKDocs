---
title: "Pool"
description: "client.pool(outcomeToken, { market, outcomeIndex }) — one named outcome on the market AMM."
---

The handle is the outcome token plus market context. That is how the SDK finds this market's OutcomeAmm.

```ts
const pool = client.pool(outcomeToken, { market: marketAddress, outcomeIndex: 0 })
```

Size with `quoteTrade`. Display mids live on `market.prices()`. Invalid is not tradable.

## State

Prefer `quoteTrade.spotPrice` / `priceAboveNinetyNineCents` for trade gates.

### state

Whether the AMM has pool shares (`totalSupply > 0`).

| Field | Live meaning |
| ----- | ------------ |
| `status` | `"open"` if `totalSupply > 0`, else `"uninitialized"` |
| `liquidity` | AMM `totalSupply` (ERC-20 pool shares) |
| `poolId` | OutcomeAmm address |

```ts
const { status, liquidity, poolId } = await pool.state()
```

```ts
// returns (read these)
Promise<{
  status: "uninitialized" | "open"
  liquidity: bigint
  poolId: Hex
}>
```

### PoolStatus / PoolState

```ts
type PoolStatus = "uninitialized" | "open"

type PoolState = {
  status: PoolStatus
  liquidity: bigint
  poolId: Hex
}
```

### spotPrice

Live named-outcome mid from `OutcomeAmm.prices()`, scaled from 1e18. `null` if the slot has no price.

```ts
const mid = await pool.spotPrice()
```

```ts
// returns
number | null
```

### quoteTrade

Exact-in quote matching `swap` sides: buy = collateral → outcome; sell = the reverse. May return a capped size when the request cannot fill (`withinRange: false`).

```ts
const quote = await client.pool(outcomeToken, { market, outcomeIndex }).quoteTrade({
  side: "buy",
  amountIn: 5_000_000n,
})
```

```ts
// returns
Promise<{
  requestedAmountIn: bigint
  amountIn: bigint
  amountOut: bigint
  withinRange: boolean
  maxAmountIn: bigint
  message?: string
  error?: "EXCEEDS_RANGE"
  spotPrice?: number | null
  priceAfter?: number | null
  priceAboveNinetyNineCents?: boolean
}>
```

### QuoteTradeResult

- `requestedAmountIn` — size you asked for
- `amountIn` — size this `amountOut` applies to (may be capped)
- `amountOut` — expected out for `amountIn`
- `withinRange` — whether the full request quoted successfully
- `maxAmountIn` — largest size that still quotes
- `message?` / `error?: "EXCEEDS_RANGE"` — when capped
- `spotPrice?` / `priceAfter?` — mid before / after (after currently equals spot)
- `priceAboveNinetyNineCents?` — current spot already above 0.99

```ts
type QuoteTradeResult = {
  requestedAmountIn: bigint
  amountIn: bigint
  amountOut: bigint
  withinRange: boolean
  maxAmountIn: bigint
  message?: string
  error?: "EXCEEDS_RANGE"
  spotPrice?: number | null
  priceAfter?: number | null
  priceAboveNinetyNineCents?: boolean
}
```

### swap

Exact-in swap via OutcomeAmm (`buy` / `sell`) and the client sender.

```ts
const result = await pool.swap({
  side: "buy",
  amountIn: quote.amountIn,
  minAmountOut: quote.amountOut * 99n / 100n,
  user: owner,
})
```

```ts
// returns
Promise<unknown>
```

Opaque sender result (same shape as your `sendCalls` / wallet path). After resolve, the AMM reverts `Resolved`.
