---
title: "Market"
description: "client.market(addr) — protocol reads, metadata, seed, resolve, LP."
---

You get this from `client.market(address)`, not from the package root.

```ts
const market = client.market(address)
```

`summary` is the protocol object. **Metadata is a separate read.**

## Reads

### summary

Name, outcomes, tokens, resolved. Indexer first, then chain. No images, no description.

```ts
const summary = await market.summary()
// market.summary({ rpcOnly: true })
```

```ts
Promise<{
  address: Address
  marketName: string
  outcomes: string[]
  resolver: Address
  resolverKind: "admin" | "committee"
  marketAdmin: Address
  threshold: number | null
  resolutionMode: number
  conditionId: `0x${string}`
  resolved: boolean
  winningOutcome: number | null
  wrappedTokens: Address[]
  numOutcomes: number
  outcomeStats?: Array<{
    index: number
    impliedPct: number | null
    liquidityCollateral: bigint | null
    volumeCollateral: bigint | null
  }>
} | null>
```

### metadata

Off-chain document pointed at by `metadataURI`, or `null`.

```ts
const metadata = await market.metadata()
```

```ts
Promise<{
  version: 1
  image: string | null
  outcomeImages: (string | null)[]
  description: string | null
  resolutionCriteria: string | null
  [key: string]: unknown
} | null>
```

### priceHistory

Chart points. Soft-fails to `[]` if the indexer is down.

```ts
await market.priceHistory({ from: Math.floor(Date.now() / 1000) - 86400 })
```

### prices

Named-outcome display mids (`0 .. numOutcomes-1`). **Not** a trade quote — use `pool.quoteTrade`. Indexer first, then live `OutcomeAmm.prices()`. Resolved markets return 1/0 via `resolvedDisplayRows` (winner `impliedPct` 100, others 0). Invalid is **not** in `rows`.

```ts
const { source, rows } = await market.prices()
```

```ts
// returns OutcomePrices
Promise<{
  source: "indexer" | "rpc"
  rows: Array<{
    index: number
    label: string
    token: Address
    priceCt: number | null
    impliedPct: number | null
  }>
}>
```

### metrics

Liquidity + volume per named outcome. Indexer `outcome` table first; RPC fallback has `volumeCollateral: null`.

```ts
const { source, rows } = await market.metrics()
```

```ts
// returns OutcomeMetrics
Promise<{
  source: "indexer" | "rpc"
  rows: Array<{
    index: number
    liquidity: bigint | null
    volumeCollateral: bigint | null
  }>
}>
```

### seedStatus / canResolve

```ts
await market.seedStatus() // "none" | "seeded" (AMM totalSupply > 0)
await market.canResolve(user)
```

## Writes

### setMetadata

Low-level write. Prefer `client.createMarket({ metadata })` when you are creating — that path deploys, then calls this for you.

Uploads files through the proxy if you pass `File` / `Blob`, then sets `metadataURI`. Needs `IMAGE_ROLE` (the creator has it).

```ts
await market.setMetadata({
  description,
  resolutionCriteria,
  image,          // File | Blob | url | null
  outcomeImages,  // same, per outcome
})
```

```ts
Promise<{ uri: string }>
```

### seed

First LP: collateral approve + `OutcomeAmm.addFunding` with named-outcome odds and Invalid weight 0, in **one** `sendCalls` batch.

```ts
await market.seed({ seedWei, oddsBps, owner })
```

### resolve / merge / redeem / LP

```ts
await market.resolve({ outcomeIndex: 0 })
await market.merge({ amount, owner })
await market.redeem({ indexes, amounts, owner })
await market.addLiquidity({ credits, owner })
await market.removeFunding({ shares, owner })
await market.redeemLp({ shares, owner }) // resolved only
await market.pauseTrading({ owner })     // creator, one-way
```

Admin `resolve` passes `requiredSigner: marketAdmin` for AA routing. A plain wallet ignores that hint.

`createMarket({ seedWei, oddsBps })` is create-and-seed on the factory. Omit `seedWei` for create-only.
