Import from `@voiz-digital/markets-sdk`. In React, take `useVoiz().client` instead of constructing by hand.

```ts
const client = new VoizMarketsClient({
  chainId,
  publicClient,
  walletClient, // or sendCalls
})
```

```ts
type ClientConfig = {
  chainId?: number
  addresses?: AddressOverrides
  publicClient?: PublicClient
  walletClient?: WalletClient
  sendCalls?: SendCalls
}
```

## Factories

`VoizMarket` / `VoizPool` / `VoizUser` are not package-root exports.

```ts
client.market(marketAddress)
client.pool(outcomeToken)
client.user(walletAddress)
```

## Catalog

```ts
await client.listMarkets()
// { markets, source: "indexer" | "rpc", usedFallback }
```

`markets` is protocol-only `MarketSummary[]`. Pictures: `client.market(addr).metadata()`.

```ts
await client.listMarketAddresses()
await client.isMarket(address)
await client.getCollateralBalance(owner)
await client.getErc20Balance(token, owner)
```

## Writes

### createMarket

Deploys the market, then — if you passed a `metadata` bag with copy or images — uploads files and sets `metadataURI`. Empty metadata is skipped. Seed is still a second call.

```ts
const { marketAddress, metadataUri } = await client.createMarket({
  marketName,
  outcomes,
  resolverKind: "admin",
  marketAdmin,
  metadata: {
    description,
    resolutionCriteria,
    image,          // File | Blob | url | null
    outcomeImages,  // same, per outcome
  },
})
```

```ts
Promise<{
  result: unknown
  hashes: Hash[]
  marketAddress?: Address
  metadataUri?: string
}>
```

If metadata is present but the new address cannot be parsed from the receipt, it throws instead of leaving a silent unpublished market.

### Other writes

```ts
await client.redeem({ marketAddress, indexes, amounts, owner })
await client.burn({ tokenId, outcomeToken, recipient })
await client.mintCollateral({ to, amount }) // testnet collateral, if the token exposes mint
```

Prefer `market.redeem` when you already have the market handle. `createMarket` is the one write that must live on the client — there is no market yet.
