---
title: "User"
description: "client.user(addr) — that wallet's fills, share book, and AMM LP shares."
---

Indexer reads. Soft-fail to `[]` if Ponder is down.

```ts
const user = client.user(address)
await user.trades()
await user.sharePositions()
await user.lpPositions({ market })
```

Three books. Do not mix them.

| Method | Book |
| ------ | ---- |
| `trades()` | OutcomeAmm `Buy` / `Sell` fills |
| `sharePositions()` | Indexer `sharePosition` only (no live ERC-20 overlay) |
| `lpPositions()` | OutcomeAmm ERC-20 pool shares (one lot per market) |

## Methods

### trades

Indexed trade history. Soft-fails to `[]` if the indexer is down.

```ts
const fills = await client.user(addr).trades({ market, limit: 50 })
```

```ts
// returns
Promise<Array<{
  id: string
  marketId: Address
  marketName: string
  outcomeIndex: number
  outcomeLabel: string
  side: "buy" | "sell"
  outcomeAmount: bigint
  collateralAmount: bigint
  priceCt: number
  timestamp: string
  transactionHash: Hex
}>>
```

Swap fees live in the indexer `hook_fee` table, not on the trade row.

### sharePositions

Outcome share book: one row per (market, outcome) with net shares and average entry. Soft-fails to `[]`.

Source of truth is indexer `sharePosition`. Inventory, remaining cost, and realized PnL come from that table. Mark `priceCt` comes from indexer `outcome` (0/1 after resolve). Raw fills stay on `trades()`. AMM LP lots stay on `lpPositions()`.

```ts
const book = await user.sharePositions({ markets: summaries })
```

```ts
// returns
Promise<Array<{
  marketId: Address
  marketName: string
  outcomeIndex: number
  outcomeLabel: string
  token: Address
  shares: bigint
  avgEntryPriceCt: number | null
  costCollateral: bigint | null
  priceCt: number | null
  resolved: boolean
  winningOutcome: number | null
  redeemed: boolean
  realizedPnlCollateral: bigint
}>>
```

Open lots with `shares == 0` are dropped. After resolve, a fully exited lot stays (`redeemed: true`) so the profile can show Redeemed.

PnL for a lot:

```
markValue     = shares * priceCt          // 0 or 1 after resolve
unrealized    = markValue - costCollateral
pnl           = realizedPnlCollateral + unrealized
```

### lpPositions

Indexed OutcomeAmm ERC-20 pool-share lots. One row per (user, market). Soft-fails to `[]`. Rows with `shares == 0` and `realizedPnlCollateral == 0` are omitted.

```ts
const one = await user.lpPositions({ market: marketAddress })
const all = await user.lpPositions()
```

```ts
// returns
Promise<Array<{
  marketId: Address
  marketName: string
  poolId: Address
  shares: bigint
  costCollateral: bigint
  realizedPnlCollateral: bigint
  currentValueCollateral: bigint | null
  pnlCollateral: bigint | null
}>>
```

`currentValueCollateral` is the named-outcome basket marked at indexer `priceCt` (0/1 if resolved), pro-rata to `shares / lpSupply`. `pnlCollateral` is realized + unrealized when mark is available.

## Related types

Param bags and aliases. Return DTOs are the typed blocks on each method above.

| Type | Fields |
| ---- | ------ |
| `UserTradesParams` | `market?: Address`, `limit?: number` |
| `UserPositionsParams` | `markets?: Address[] \| MarketSummary[]` — filter; summaries also supply labels / tokens / resolution. Inventory still comes from the indexer. |
| `UserLpPositionsParams` | `market?: Address` |
