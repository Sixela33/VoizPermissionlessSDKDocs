Scripts, backends, or a UI that is not React — still one `VoizMarketsClient`.

## Install

```bash
npm install @voiz-digital/markets-sdk viem
```

## Create a client

```ts
import { VoizMarketsClient, getAddresses } from '@voiz-digital/markets-sdk'
import { createPublicClient, createWalletClient, http } from 'viem'
import { privateKeyToAccount } from 'viem/accounts'
import { baseSepolia } from 'viem/chains'

const chainId = baseSepolia.id
const publicClient = createPublicClient({
  chain: baseSepolia,
  transport: http(),
})

const account = privateKeyToAccount(process.env.PRIVATE_KEY as `0x${string}`)
const walletClient = createWalletClient({
  account,
  chain: baseSepolia,
  transport: http(),
})

const client = new VoizMarketsClient({
  chainId,
  publicClient,
  walletClient,
  // sendCalls,  // AA batcher if you have one
  // addresses: getAddresses(chainId, { /* overrides */ }),
})
```

`walletClient` → one tx per inner call. `sendCalls` → one UserOp for the batch. High-level methods pick whichever you passed.

## Look around

```ts
const { markets } = await client.listMarkets()

const market = client.market(markets[0].address)
await market.summary()
await market.metadata() // copy + images, or null
```

## Create with metadata

```ts
const { marketAddress } = await client.createMarket({
  marketName: 'Will ETH be above 5k?',
  outcomes: ['Yes', 'No'],
  resolverKind: 'admin',
  marketAdmin: account.address,
  metadata: {
    description: '…',
    resolutionCriteria: '…',
    image: file,
    outcomeImages: [yesFile, noFile],
  },
})
```

## Seed

Preview collateral with `quoteSeed` (works before the market exists). The write is `market.seed`.

```ts
import { normalizeOddsBps, quoteSeed } from '@voiz-digital/markets-sdk'

const oddsBps = normalizeOddsBps([50, 50])
const seedWei = 10n ** 18n
const { totalCollateral } = quoteSeed({ seedWei, oddsBps })

const market = client.market(marketAddress)
const summary = await market.summary()
if (!summary) throw new Error('Market not found')

await market.seed({ seedWei, oddsBps, owner: account.address })
```

You can pass `outcomeTokens` if you already have them; otherwise the market loads them.

## Quote and swap

```ts
const outcomeIndex = 0
const outcomeToken = summary.wrappedTokens[outcomeIndex]!
const pool = client.pool(outcomeToken, {
  market: marketAddress,
  outcomeIndex,
})
const quote = await pool.quoteTrade({ side: 'buy', amountIn })

await pool.swap({
  side: 'buy',
  amountIn: quote.amountIn,
  minAmountOut: (quote.amountOut * 99n) / 100n,
  user: account.address, // token holder = msg.sender (AA smart wallet, not a nested EOA)
})
```
