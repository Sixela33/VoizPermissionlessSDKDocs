You are adding the package so the rest of these docs can run.

The SDK talks to a chain. You still need an RPC when you build the client. Reads work with that alone. Writes need a wallet, and they spend the market’s collateral — USDC on Base and Polygon for a question like “Will ETH be above $5,000 at year end?”

<CodeGroup>

```bash npm
npm install @voiz-digital/markets-sdk viem
```

```bash pnpm
pnpm add @voiz-digital/markets-sdk viem
```

```bash yarn
yarn add @voiz-digital/markets-sdk viem
```

</CodeGroup>

React apps also want `react`, then import `@voiz-digital/markets-sdk/react`.

In code, the RPC is a `publicClient`. Writes also need a `walletClient` or `sendCalls`.
