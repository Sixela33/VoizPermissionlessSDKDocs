---
title: "Create a market"
description: "Pass metadata on createMarket, then seed."
---

The factory has to mint the market before anything can point at it. `createMarket` does that, then — if you passed `metadata` — uploads files and sets `metadataURI`. Seed is still a second call.

## You need

A client that can send (`walletClient` or `sendCalls`), and a wallet with gas.

## Create (and describe)

Admin markets need `marketAdmin`. Committee markets need `voters` and `threshold`. `image` / `outcomeImages` can be a `File`, a `Blob`, or a public URL.

```ts
const { marketAddress } = await client.createMarket({
  marketName: 'Will ETH be above 5k?',
  outcomes: ['Yes', 'No'],
  resolverKind: 'admin',
  marketAdmin: yourAddress,
  metadata: {
    description: '…',
    resolutionCriteria: 'Coinbase ETH-USD at 23:59 UTC.',
    image: marketImageFile,
    outcomeImages: [yesFile, noFile],
  },
})

if (!marketAddress) {
  throw new Error('Created, but the receipt did not include the new address')
}

const market = client.market(marketAddress)
```

Skip `metadata` if you have nothing to publish. After the market is live, treat the document as frozen in the product UI. `market.setMetadata` still exists for a retry if the upload failed after create.

## Seed

See [Seed liquidity](/guides/seed). Preview with `quoteSeed` first so the user knows how much collateral they will lock.

```ts
import { normalizeOddsBps, quoteSeed } from '@voiz-digital/markets-sdk'

const oddsBps = normalizeOddsBps([50, 50])
const { totalCollateral } = quoteSeed({ seedWei, oddsBps })

await market.seed({ seedWei, oddsBps, owner: yourAddress })
```
