---
title: "Provide liquidity"
description: "One collateral amount, split across every open outcome."
---

You put in `credits`. Half becomes a complete set of shares; the rest pairs those shares in each open pool. That is `market.addLiquidity` — use it instead of per-pool helpers.

For inventory, fees, resolution, and leftover Invalid, read [How liquidity provision works](/guides/liquidity) first.

## You need

A seeded market (`seedStatus() === 'seeded'`), enough collateral, and `owner` as the connected wallet. Unopened pools are skipped by default.

```ts
const market = client.market(marketAddress)
const summary = await market.summary()
const credits = parseUnits('50', 18)

await market.addLiquidity({
  credits,
  owner: yourAddress,
  outcomeLabels: summary?.outcomes, // "Providing to Yes (1/2)…"
  setProgress,
})
```

Useful knobs: `continueOnError` to skip a failed outcome instead of aborting; `skipUninitialized` (default true). Tiny `credits` fail with “Amount too small…”.

Leave later with `client.burn({ tokenId, outcomeToken, recipient })`. Find open LP via `client.user(addr).lpPositions(…)`.
