---
title: "Seed a market"
description: "quoteSeed to preview, market.seed to open the pools."
---

Seeding is how a market becomes tradable. Quote the collateral first (pure math), then call `market.seed`. There is no `client.seedMarket`.

## You need

The market address, enough collateral for `quoteSeed(…).totalCollateral`, and `owner` as the connected wallet.

## 1. Quote

Odds are percents. We turn them into basis points that sum to 10_000 (each outcome 1%–99%).

```ts
import { normalizeOddsBps, quoteSeed } from '@voiz-digital/markets-sdk'
import { parseUnits } from 'viem'

const seedWei = parseUnits('100', 18) // match collateral decimals
const oddsBps = normalizeOddsBps([60, 40])

const { splitAmount, poolCollateral, totalCollateral } = quoteSeed({
  seedWei,
  oddsBps,
})
// Show totalCollateral before they confirm — that is what they lock, not just seedWei.
```

This works **before** the market exists. Handy on the create screen.

## 2. Seed

```ts
const market = client.market(marketAddress)

await market.seed({
  seedWei,
  oddsBps,
  owner: yourAddress,
})
```

That is **one** `sendCalls` batch: split + every outcome init/mint. On AA, one UserOp. On a plain wallet, still one signature per inner call. Pools that are already open skip `initialize`.

Outcome tokens default from the market; pass `outcomeTokens` if you already loaded them (real outcomes only — not Invalid).

```ts
await market.seedStatus() // 'none' | 'partial' | 'seeded'
```
