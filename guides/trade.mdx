---
title: "Trade an outcome"
description: "Quote live against the AMM, then swap. Never size from display prices."
---

You trade **one named outcome against collateral** on the market's OutcomeAmm. The handle is the outcome token plus `{ market, outcomeIndex }`.

`prices()` is for the UI. `quoteTrade` is for the button.

## You need

A seeded market, collateral (buy) or shares (sell), and `summary.wrappedTokens[index]` for a **named** outcome. Invalid is not tradable.

## 1. Get the pool

```ts
const summary = await client.market(marketAddress).summary()
const outcomeIndex = 0
const outcomeToken = summary!.wrappedTokens[outcomeIndex]!
const pool = client.pool(outcomeToken, {
  market: marketAddress,
  outcomeIndex,
})
```

## 2. Quote exact-in

```ts
const quote = await pool.quoteTrade({
  side: 'buy', // or 'sell'
  amountIn,
})

// quote.amountOut is for quote.amountIn (may be smaller than you asked)
// withinRange === false → you asked more than the AMM can fill
```

If it capped you, swap `quote.amountIn`, not the original number.

## 3. Swap

```ts
await pool.swap({
  side: 'buy',
  amountIn: quote.amountIn,
  minAmountOut: (quote.amountOut * 99n) / 100n, // your slippage
  user: yourAddress, // token holder = AA smart wallet, not a nested EOA
})
```

Buy is collateral → outcome (`OutcomeAmm.buy`). Sell is the reverse (`OutcomeAmm.sell`). Quote again right before you send — mids from the indexer can be stale.

A buy of one named outcome **does** move the others: the AMM splits a complete set, pays out the bought outcome, and keeps the rest. Named prices stay `p_i ∝ 1/x_i` and still sum to 1. After resolve, swaps revert.
