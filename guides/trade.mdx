---
title: "Trade an outcome"
description: "Quote live, then swap. Never size from display prices."
---

You trade **one outcome against collateral**. The handle is the outcome token, not the market.

`prices()` is for the UI. `quoteTrade` is for the button.

## You need

A seeded market, collateral (buy) or shares (sell), and `summary.wrappedTokens[index]` for a real outcome.

## 1. Get the pool

```ts
const summary = await client.market(marketAddress).summary()
const outcomeToken = summary!.wrappedTokens[0]!
const pool = client.pool(outcomeToken)
```

## 2. Quote exact-in

```ts
const quote = await pool.quoteTrade({
  side: 'buy', // or 'sell'
  amountIn,
})

// quote.amountOut is for quote.amountIn (may be smaller than you asked)
// withinRange === false → you asked more than the prediction range allows
```

If it capped you, swap `quote.amountIn`, not the original number.

## 3. Swap

```ts
await pool.swap({
  side: 'buy',
  amountIn: quote.amountIn,
  minAmountOut: (quote.amountOut * 99n) / 100n, // your slippage
  user: yourAddress, // token holder = AA smart wallet, not a nested EOA
})
```

Buy is collateral → outcome. Sell is the reverse. Quote again right before you send — mids from the indexer can be stale.

A trade in **one** pool does not move the others. If the book’s prices no longer sum to ~1, the [rebalancer](/protocol) trades complete sets against Uniswap until they do.
