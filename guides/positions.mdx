---
title: "Read user positions"
description: "Shares, fills, and LP NFTs via client.user(addr)."
---

Three books, three methods. Do not mix them.

```ts
const user = client.user(walletAddress)

await user.sharePositions()                         // net shares + avg entry
await user.trades({ market, limit: 50 })            // fills
await user.lpPositions({ market, wrappedTokens })   // Uniswap v4 NFTs
```

Indexer down → `[]`, not a throw. Trading still works off RPC.

Pass `MarketSummary[]` into `sharePositions({ markets })` if you want live ERC-20 balances on those rows.

Catalog cards still want `listMarkets()` for names and `client.market(addr).metadata()` for pictures. Display prices: `market.prices()`. Size a trade with `pool.quoteTrade`.
