---
title: "Read user positions"
description: "Shares, fills, and AMM LP lots via client.user(addr)."
---

Three books, three methods. Do not mix them.

```ts
const user = client.user(walletAddress)

await user.sharePositions()              // indexer share book
await user.trades({ market, limit: 50 }) // Buy / Sell fills
await user.lpPositions({ market })       // OutcomeAmm ERC-20 pool shares
```

Indexer down → `[]`, not a throw. Trading still works off RPC.

## Share book

`sharePositions()` is indexer `sharePosition` only. There is no live ERC-20 overlay.

The indexer updates lots from:

| Event | Effect |
| ----- | ------ |
| OutcomeAmm `Buy` / `Sell` | Avg-cost trade (buy adds shares + cost; sell reduces and realizes PnL) |
| Wrapped outcome `Transfer` **to the AMM `router()`** | Share-book **exit** (treated as a sell). There is no resolved-only gate. |

Proceeds on a Router transfer:

| Condition | `collateralAmount` booked |
| --------- | ------------------------- |
| Market **resolved** and this outcome **is the winner** | `amount` |
| Otherwise (open market, loser, or Invalid) | `0` |

That includes post-resolve **redeem** (winner proceeds = amount) and an open-market `market.merge` (Router pulls wrapped tokens; proceeds = 0). A merge that empties an **open** lot is dropped (`shares == 0` and not resolved). After resolve, a full exit stays (`redeemed: true`).

PnL for a remaining lot is `realizedPnlCollateral + (shares * priceCt − costCollateral)`. After resolve, mark is 1 for the winner and 0 otherwise.

Zero-share lots on an **open** market are dropped. Zero-share lots on a **resolved** market stay (`redeemed: true`) so the UI can show Redeemed.

Pass `MarketSummary[]` into `sharePositions({ markets })` only to filter and to supply labels / tokens / resolution. Inventory still comes from the indexer.

## LP book

`lpPositions()` is one ERC-20 pool-share lot per market (`lpPosition` id = user + market).

| Event | Effect |
| ----- | ------ |
| `FundingAdded` | Cost += `max(amountsAdded)` (that is `addedFunds`) |
| `FundingRemoved` | Realize PnL; proceeds = named basket at 1e18 prices (0/1 if resolved) |
| LP token `Transfer` | Move cost with the shares. Mint/burn (zero address) is ignored — those are already in add/remove. |

Mark is the named-outcome basket, pro-rata to `shares / lpSupply`.

## Display vs size

Catalog cards still want `listMarkets()` for names and `client.market(addr).metadata()` for pictures. Display prices: `market.prices()`. Size a trade with `pool.quoteTrade`.
