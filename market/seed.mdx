---
title: "Seed a market"
description: "Put in the first collateral so people can trade."
---

The ETH market exists, but nobody can trade until the first collateral is in. You are that first deposit. You are not placing a bet on Yes or No. You are stocking the market maker and choosing how the starting inventory is split.

If you can still do this at create time, pass the deposit there. Otherwise preview the amount, then seed. There is no `client.seedMarket`.

You need the market address, enough collateral for the quoted total, and the connected wallet as owner. Odds are percents. A helper turns them into basis points that sum to 10_000 (each answer 1%–99%). Invalid has no opening weight.

```ts
import { normalizeOddsBps, quoteSeed } from '@voiz-digital/markets-sdk'
import { parseUnits } from 'viem'

const seedWei = parseUnits('100', 18) // match collateral decimals
const oddsBps = normalizeOddsBps([60, 40])

const { splitAmount, poolCollateral, totalCollateral } = quoteSeed({
  seedWei,
  oddsBps,
})
// Show totalCollateral before they confirm — for OutcomeAmm this equals seedWei.

await market.seed({
  seedWei,
  oddsBps,
  owner: yourAddress,
})
```

That is **one** `sendCalls` batch: collateral approve plus `addFunding`. With account abstraction, that is one UserOp. With a plain wallet, you still sign once per inner call.

`quoteSeed` does not need a market yet. It returns a total equal to the deposit (one complete-set deposit). Later liquidity is [`market.addLiquidity`](/market/add-liquidity), which joins current proportions with an empty hint.

```ts
await market.seedStatus() // 'none' | 'seeded'  (AMM totalSupply > 0)
```
