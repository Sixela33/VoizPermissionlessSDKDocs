---
title: "List markets"
description: "Catalog addresses and protocol summaries from the indexer, with RPC fallback."
---

You are drawing a catalog of questions. For each row you get the name and the answers — for example “Will ETH be above $5,000 at year end?” with Yes and No. Pictures and descriptions are not on this list. Load those with [`market.metadata()`](/market/get-metadata).

```ts
const { markets, source, usedFallback } = await client.listMarkets()
// source: "indexer" | "rpc"
```

```ts
await client.listMarketAddresses()
await client.isMarket(address)
```

If the indexer is down, `listMarkets` falls back to RPC and returns `{ source: "rpc", usedFallback: true }`. Do not treat an empty catalog as “indexer down”.
