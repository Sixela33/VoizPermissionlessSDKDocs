---
title: "Set market metadata"
description: "Upload files and set metadataURI on an existing market."
---

You are attaching pictures and copy to a market that already exists — the ETH question’s image, description, and resolution rules. Prefer passing them when you create. This page is the retry, or the path you skipped on create. In the product UI, treat the live document as frozen once it is set.

If you pass a file or blob, the client uploads through the proxy, then sets the market’s metadata URI. You need permission to set the image (the creator has it).

```ts
await market.setMetadata({
  description,
  resolutionCriteria,
  image,          // File | Blob | url | null
  outcomeImages,  // same, per outcome
})
```

```ts
Promise<{ uri: string }>
```
