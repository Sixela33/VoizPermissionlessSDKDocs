---
title: "Get market metrics"
description: "Liquidity and volume per named outcome."
---

You are filling a stats strip: liquidity and volume per answer on the ETH market. This is not the mid on the card, and it is not a trade size. The pool’s share supply lives on pool state, not on these rows.

The SDK tries the indexer first. On chain fallback, volume is null.

```ts
const { source, rows } = await market.metrics()
```

```ts
// returns OutcomeMetrics
Promise<{
  source: "indexer" | "rpc"
  rows: Array<{
    index: number
    liquidity: bigint | null
    volumeCollateral: bigint | null
  }>
}>
```
