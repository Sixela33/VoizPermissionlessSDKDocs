---
title: "Add liquidity"
description: "Put up more inventory after people can already trade."
---

You are not betting Yes on the ETH market. You are putting up more inventory after people can already trade. Later deposits join the mix the pool already has. They do not set a new opening split.

First liquidity is [`market.seed`](/market/seed) — same contract, with an opening mix (Invalid weight 0). For inventory, fees, and resolution, read [How liquidity works](/market/liquidity) first.

You need a market that already has pool shares, enough collateral, and the connected wallet as owner.

```ts
const credits = parseUnits('50', 18)

await market.addLiquidity({
  credits,
  owner: yourAddress,
  setProgress, // SDK sends "Minting shares…"
})
```

Later liquidity uses an empty distribution hint and joins **current** proportions. Tiny amounts fail with “Amount too small…”.

You receive ERC-20 pool shares, one lot per market. Find them with [`client.user(addr).lpPositions`](/user/get-lp-positions).
