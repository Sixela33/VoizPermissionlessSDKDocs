The ETH question is settled. You bought Yes, Yes won, and you want USDC. This page cashes winning answer tokens. To cash liquidity inventory, use [`redeemLp`](/market/redeem-lp).

If you already have the market handle, call `market.redeem`. If you only have the address, `client.redeem({ marketAddress, indexes, amounts, owner })` is the same write.

```ts
const summary = await market.summary()
const win = summary!.winningOutcome
await market.redeem({
  indexes: [BigInt(win!)],
  amounts: [amount],
  owner: yourAddress,
})
```

Use this for leftover / send-back named tokens as well as traded shares. LP inventory after resolve is [`redeemLp`](/market/redeem-lp).
