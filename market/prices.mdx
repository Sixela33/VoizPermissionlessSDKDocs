---
title: "Get market prices"
description: "Named-outcome display mids. Not a trade quote."
---

You are showing mids on a catalog card for the ETH question — Yes at 62%, No at 38%. That is not a size you can trade. Size a trade with [`pool.quoteTrade`](/outcome/quote-trade).

Named answers only. Invalid is not in the rows. After resolve, the winner shows 100% and the others 0. The SDK tries the indexer first, then live prices from the market maker.

```ts
const { source, rows } = await market.prices()
```

```ts
// returns OutcomePrices
Promise<{
  source: "indexer" | "rpc"
  rows: Array<{
    index: number
    label: string
    token: Address
    priceCt: number | null
    impliedPct: number | null
  }>
}>
```

Display prices can lag. Never size a swap from them.
