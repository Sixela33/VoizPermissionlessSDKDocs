---
title: "Get market data"
description: "Open a market handle and read the protocol summary."
---

You have one market address and need the protocol facts: whether it is resolved, the answers, and the tokens. For the ETH question that is Yes, No, the wrapped tokens, and whether someone has already published the result.

The catalog is [`listMarkets`](/market/list). Pictures are [`metadata()`](/market/get-metadata). Mids for the card are [`prices()`](/market/prices). Liquidity and volume for a stats strip are [`metrics()`](/market/metrics).

You get a market from `client.market(address)`, not from the package root.

```ts
const market = client.market(address)
const summary = await market.summary()
// market.summary({ rpcOnly: true })
```

Indexer first, then chain. No images, no description.

```ts
Promise<{
  address: Address
  marketName: string
  outcomes: string[]
  resolver: Address
  resolverKind: "admin" | "committee"
  marketAdmin: Address
  threshold: number | null
  resolutionMode: number
  conditionId: `0x${string}`
  resolved: boolean
  winningOutcome: number | null
  wrappedTokens: Address[]
  numOutcomes: number
  outcomeStats?: Array<{
    index: number
    impliedPct: number | null
    liquidityCollateral: bigint | null
    volumeCollateral: bigint | null
  }>
} | null>
```

Other market pages assume you already have `market`.
