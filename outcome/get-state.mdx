---
title: "Get pool state"
description: "Whether this market maker already has pool shares."
---

You have one answer on the ETH market — Yes — and you want to know whether that market maker has pool shares yet. A pool handle is one named answer on the same market maker, not a second pool. Invalid is not tradable.

Display mids for the card live on [`market.prices()`](/market/prices). Size a trade with [`quoteTrade`](/outcome/quote-trade).

```ts
const pool = client.pool(outcomeToken, { market: marketAddress, outcomeIndex: 0 })
```

`pool` requires `{ market, outcomeIndex }`. That is how the SDK finds this market’s OutcomeAmm.

For trade gates, prefer the spot fields on a quote. `state` only tells you whether the market maker already has pool shares (`totalSupply > 0`).

| Field | Live meaning |
| ----- | ------------ |
| `status` | `"open"` if `totalSupply > 0`, else `"uninitialized"` |
| `liquidity` | AMM `totalSupply` (ERC-20 pool shares) |
| `poolId` | OutcomeAmm address |

```ts
const { status, liquidity, poolId } = await pool.state()
```

```ts
Promise<{
  status: "uninitialized" | "open"
  liquidity: bigint
  poolId: Hex
}>
```

```ts
type PoolStatus = "uninitialized" | "open"

type PoolState = {
  status: PoolStatus
  liquidity: bigint
  poolId: Hex
}
```
