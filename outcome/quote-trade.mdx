---
title: "Quote a trade"
description: "Exact-in quote against the AMM. Never size from display prices."
---

You are buying Yes on “Will ETH be above $5,000 at year end?” Size comes from a quote, not from the mid on the card. Invalid is not tradable. Display mids live on [`market.prices()`](/market/prices).

You need a market people can already trade, collateral (to buy) or shares (to sell), and the token for a named answer. If the quote cannot fill the full size, swap the capped amount, not the original number.

```ts
const pool = client.pool(outcomeToken, { market: marketAddress, outcomeIndex: 0 })
const quote = await pool.quoteTrade({
  side: 'buy', // or 'sell'
  amountIn,
})
```

This is an exact-in quote with the same sides as swap: buy turns collateral into that answer; sell is the reverse. The quote may return a capped size when the full request cannot fill (`withinRange: false`). If it capped you, swap `quote.amountIn`, not the original number.

```ts
Promise<{
  requestedAmountIn: bigint
  amountIn: bigint
  amountOut: bigint
  withinRange: boolean
  maxAmountIn: bigint
  message?: string
  error?: "EXCEEDS_RANGE"
  spotPrice?: number | null
  priceAfter?: number | null
  priceAboveNinetyNineCents?: boolean
}>
```

| Field | Meaning |
| ----- | ------- |
| `requestedAmountIn` | Size you asked for |
| `amountIn` | Size this `amountOut` applies to (may be capped) |
| `amountOut` | Expected out for `amountIn` |
| `withinRange` | Whether the full request quoted successfully |
| `maxAmountIn` | Largest size that still quotes |
| `message?` / `error?: "EXCEEDS_RANGE"` | When capped |
| `spotPrice?` / `priceAfter?` | Mid before / after (after currently equals spot) |
| `priceAboveNinetyNineCents?` | Current spot already above 0.99 |

Quote again right before you send — mids from the indexer can be stale.
