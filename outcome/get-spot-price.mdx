---
title: "Get spot price"
description: "Live named-outcome mid from OutcomeAmm.prices()."
---

You want the live mid for Yes on the ETH market, from the chain. The card of all answers is [`market.prices()`](/market/prices). This is one slot, scaled from 1e18, or `null` if that slot has no price. Invalid is not tradable.

```ts
const pool = client.pool(outcomeToken, { market: marketAddress, outcomeIndex: 0 })
const mid = await pool.spotPrice()
```

```ts
number | null
```

Never size a swap from a display mid. Use [`quoteTrade`](/outcome/quote-trade).
