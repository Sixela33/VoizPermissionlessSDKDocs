title: "Swap"
description: "Exact-in buy or sell on the market OutcomeAmm."
---

You are sending the trade: buy Yes on the ETH market, or sell it back, using the size from [`quoteTrade`](/outcome/quote-trade). After the result is published, swaps revert. Invalid is not tradable. Display mids live on [`market.prices()`](/market/prices).

```ts
const pool = client.pool(outcomeToken, { market: marketAddress, outcomeIndex: 0 })
const result = await pool.swap({
  side: 'buy',
  amountIn: quote.amountIn,
  minAmountOut: (quote.amountOut * 99n) / 100n, // your slippage
  user: owner, // token holder = AA smart wallet, not a nested EOA
})
```

```ts
Promise<unknown>
```

The return value matches whatever your `sendCalls` or wallet path returns. A buy turns collateral into that answer (`OutcomeAmm.buy`). A sell is the reverse (`OutcomeAmm.sell`).

A buy of Yes **does** move No: the market maker splits a complete set, pays you Yes, and keeps the rest. Named prices still sum to 1. After resolve, swaps revert with `Resolved`.
