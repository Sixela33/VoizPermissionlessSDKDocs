Wrap once. After that, every screen just asks `useVoiz().client` for a market, a pool, or a user.

[Install](/install) the SDK, `viem`, and `react`. You still need a viem `publicClient`. Writes need a `walletClient` or an AA `sendCalls` (Privy, etc.).

## Wrap the app

```tsx
'use client'

import { VoizProvider } from '@voiz-digital/markets-sdk/react'
import { createPublicClient, http } from 'viem'
import { baseSepolia } from 'viem/chains'

const publicClient = createPublicClient({
  chain: baseSepolia,
  transport: http(),
})

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <VoizProvider
      chainId={baseSepolia.id}
      publicClient={publicClient}
      // walletClient={walletClient}
      // sendCalls={aaSendCalls}
    >
      {children}
    </VoizProvider>
  )
}
```

Skip `addresses` unless you redeployed — they come from `chainId`. Prefer `sendCalls` for AA so `seed` / `swap` / `addLiquidity` batch. A plain `walletClient` sends each inner call as its own tx.

## List markets, then ask one for pictures

```tsx
'use client'

import { useVoiz } from '@voiz-digital/markets-sdk/react'

export function MarketList() {
  const { client } = useVoiz()

  async function load() {
    const { markets } = await client.listMarkets()
    const metadata = await client.market(markets[0].address).metadata()
    console.log(markets[0].marketName, metadata?.image)
  }

  return <button onClick={load}>Load markets</button>
}
```

`useVoiz()` throws outside the provider. That is on purpose.
