title: "VOIZ Markets SDK"
description: "One client. A living market. OutcomeAmm underneath."
---

VOIZ turns a question into a live market. This SDK is how you talk to that market: one client, then a market, a pool, or a user. Viem is underneath. You do not assemble calldata.

```ts
client.listMarkets()
client.market(address)                         // summary, metadata, seed, resolve, LP
client.pool(outcomeToken, { market, outcomeIndex }) // quote, swap
client.user(owner)                             // trades, share book, AMM LP shares
```

A **market** is the protocol object. **Metadata** (description, resolution rules, images) is a separate **read** on that same market — it is not mixed into the catalog. You **write** it by passing `metadata` into `createMarket`.

Each market has **one** complete-set OutcomeAmm. You trade named outcomes against that AMM. Invalid is an extra CT slot, priced at 0, and is not tradable. LP inventory math: [calculator](/guides/lp-calculator).

## Install

<CodeGroup>

```bash npm
npm install @voiz-digital/markets-sdk viem
```

```bash pnpm
pnpm add @voiz-digital/markets-sdk viem
```

```bash yarn
yarn add @voiz-digital/markets-sdk viem
```

</CodeGroup>

React apps also want `react`, then import `@voiz-digital/markets-sdk/react`.
